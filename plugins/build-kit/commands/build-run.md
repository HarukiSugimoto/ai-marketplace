build-run skill を使って実装する。 $ARGUMENTS

**plan.md の未完タスクを全部やり切る。** 部分実行はしない。
途中のタスクだけ指定させない — 受入条件は計画全体に対して定義されているので、
途中で止めても検証が成立しない。

1. 未完タスクを先頭から順に、RED→失敗を目視→GREEN→REFACTOR で1つずつ
2. スコープ宣言に無いファイルを触る必要が出たら、**止まって選択肢を出す**(■3)
3. 全タスク完了したら、確認を待たずそのまま検証へ
4. 検証で ⚠️/❌ が出たら止まる(■4)。全部 ✅ ならそのままレポートまで
5. HTML レポートを生成して開く

計画が無ければ `/build-design` に戻す。
